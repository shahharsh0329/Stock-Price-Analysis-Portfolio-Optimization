# Stock-Price-Analysis-Portfolio-Optimization

Overview

This project analyzes historical stock prices, calculates returns, and optimizes a portfolio using Python. It employs Mean-Variance Optimization (Markowitz Model) to determine an optimal allocation based on risk-adjusted returns.

🔹 Features

 - Fetch historical stock prices using yfinance
 - Compute daily returns, volatility, and Sharpe ratio
 - Optimize portfolio allocation using scipy.optimize
 - Visualize stock trends and the Efficient Frontier

🔹 Installation & Setup

Clone the repository:

git clone https://github.com/your-username/stock-analysis-optimization.git

cd stock-analysis-optimization

Install required dependencies:

pip install -r requirements.txt

🔹 Usage

Run the Python script to analyze and optimize your portfolio:

python stock_analysis.py
